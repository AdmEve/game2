## Goal

Ship an Android APK of a Persian multiplayer drawing/guessing game to Cafe Bazaar and
Myket, and make money from it (rewarded ads + cosmetic IAP). The owner asked (2026-11-07) for the
game to be "top notch": **`docs/QUALITY_PLAN.md`** is the plan — the 18 aspects every game has,
where we stand, what's done (✅) and next (⏭). Immediate goal: **playtest it with real people**
(`PLAYTEST.md`: offline دورهمی first, then online over wifi).

## Where things are

- Repo: `AdmEve/game2` (public). Work branch: `claude/funny-heisenberg-fv8bud`.
- **Every push** runs CI (`.github/workflows/build.yml`): server tests, `flutter analyze`,
  `flutter test` (incl. the protocol test), builds the APKs, and replaces the release
  **https://github.com/AdmEve/game2/releases/tag/android-latest** with
  `Naqashi-arm64.apk` (~8.8 MB), `Naqashi-arm32.apk` (~8.3 MB), `Naqashi-universal.apk` (~24 MB)
  and `naqashi-server.js` (single-file server, needs only Node).
- The owner does not need Flutter, a JDK or the Android SDK on the laptop. Only Node, for the
  playtest server.

## Step 1 — Toolchain and build ✅ (2026-11-03)

Done in a cloud session; see the session log. Notes for whoever builds next:
- Flutter **3.47.9** (owner chose current stable over the old 3.24 pin). Android scaffolding is
  committed; no `flutter create` step any more. applicationId **`ir.naqashi.naqashi`** — permanent
  once it's on Bazaar; change it before the first upload if you want something else.
- Native libs are compressed in the APK (`useLegacyPackaging = true`): halves the download.
- `permission_handler` was removed (unused; its Android plugin needs an SDK platform name the SDK
  repository doesn't serve). Re-add a mic-permission solution with voice.
- Cloud machines: Maven Central rate-limits them (HTTP 429). A user-level Gradle init script that
  points Maven Central at Google's mirror (`maven-central.storage-download.googleapis.com`) fixes it;
  it is *not* in the repo (CI doesn't need it). See CLAUDE.md.

## Step 3 — Close the gap between prototype and app

The web prototype has things the Flutter app lacks. Port, in this order:
1. **Undo + eraser** in the drawing tools.
2. **Live stroke streaming** — currently only completed strokes are sent, so guessers see
   nothing until the drawer lifts their finger. Send throttled point batches while drawing.
3. ~~Solver state on the client~~ — done: solver sees the word, «حلش کردی», solver-chat hint.
   Still to do: 🔒 on solved players' avatars (needs a player strip on the game screen).
4. ~~Near-miss «نزدیکه» private to the guesser~~ — verified (protocol test + screenshots).
5. **Save/share drawing** as PNG via the platform share sheet (Telegram/WhatsApp are the main acquisition channel).
6. **Custom word packs** (local, persisted) — needs a protocol addition so the host can choose a pack.

## Step 4 — Server hardening (before strangers play)

- ~~Drawer disconnect mid-turn~~, ~~player leaving mid-game~~ — done and tested.
- **"Play again"** — after `over`, reset the room to lobby.
- **Reconnection grace period** — Android may drop the socket when the app is backgrounded; expect
  this to be the first playtest complaint.
- Rate limit `guess` and `stroke` (payload is already capped at 256 KB; a socket error no longer
  crashes the server).
- Reporting flow (`{t:'report'}`) persisted somewhere a human can review — prerequisite for ever enabling voice in public rooms.
- Expand the word bank (currently ~30 words) and the alias table; this is a content task, not a code one.
- Deploy: a cheap Iran-hosted VPS (low ping to the audience), TLS (`wss://`), process manager.

## Step 5 — Voice (private rooms only)

Needs an SFU beside the game server (LiveKit self-hosted or mediasoup). Rules to enforce
**as media routing**, not UI: drawer silent in team mode; solved players audible only to
solved players; `hostMuted` players audible to nobody; local mute is client-side. Flip
`kVoiceBuilt` when it works. Decide hosting before choosing — WebRTC from inside Iran has its
own reachability problems; verify with real devices. Until then consider dropping
`RECORD_AUDIO` from the manifest before a store submission (an unused mic permission invites review questions).

## Step 6 — Money and release

- **Billing:** Cafe Bazaar in-app billing via the Poolakey library (a Flutter plugin exists; check it is maintained), plus Myket's equivalent. **Not Google Play Billing.**
- **Ads:** Tapsell or Adivery, rewarded video for hints/colour unlocks; at most one interstitial every ~3 rounds.
- **IAP:** avatar sets, brush/colour packs, premium word packs, ad-free pass. **No loot boxes** (Bazaar requires odds disclosure and it invites review trouble).
- **Release signing:** create the real keystore once, keep it safe forever (losing it = can never
  update the Bazaar app). Add repository secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
  `KEY_ALIAS`; CI then signs every build with it, and playtest builds install over each other.
  Never commit it — the repo is public.
- `usesCleartextTraffic="false"`, `wss://`, real app icon. Version code = CI run number.
- Content rules: no gambling, no sexual content, nothing politically or religiously sensitive; Persian localisation is mandatory.

## Competitor note — تخته گچی (low confidence)

The owner reported a game called **تخته گچی** on Cafe Bazaar (package `com.takhtegachi`) with ~42,000 users.
From search snippets only (never played or installed by the previous assistant, and results may blend
several similarly-named apps, including a Myket "چارتخته (تخته گچی)" variant): it appears to be a
chalkboard-themed group guessing game dating back to ≥2018; one description says guessers pick
from provided options rather than typing; chat may be preset phrases only; one variant showed
~2.0/5 from ~40 Myket reviews with "bring back the old version" complaints. **None of this is
confirmed.** The owner should install it and check: free-text vs multiple-choice guessing; whether
players draw live; voice; chat; teams; monetisation; current rating and recent reviews; drawing feel.
Intended differentiators (if the above holds): free-text Persian guessing with real normalisation,
live player drawing, moderated free chat, private-room voice, team mode.
